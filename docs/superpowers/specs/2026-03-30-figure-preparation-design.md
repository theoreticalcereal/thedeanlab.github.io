# Figure Preparation Page Design

## Goal

Add a standalone `figure-preparation` page under `Lab Resources` that formalizes the lab's expectations for manuscript-ready figures and captures a small set of objective non-negotiables that can be referenced during one-on-one meetings and manuscript preparation.

## Approved Decisions

- The guidance should live on its own top-level handbook page.
- The page should be easy to expand later.
- The lab's own rules should be separated from journal-specific instructions and generic publisher guidance.
- The attached Nature guide should inform the page, but it should not override target-journal requirements.

## Content Structure

- `Purpose`: explain that the page defines the lab standard for manuscript-ready figure drafts
- `Core Principle`: figures should match the target journal's requested specifications whenever those are known
- `Lab Non-Negotiables`: objective rules on font family, final-size label size, line weights, panel labels, vector text, AI-image use, and the two-second test
- `Journal Specifications`: target-journal artwork guidance takes precedence for submission details
- `Working Standard When Journal Guidance Is Unclear`: use vector outputs, editable text, readable labels, and consistent layout
- `Notes from the Nature Guide`: summarize the most useful general lessons from the attached PDF without overfitting the page to one publisher
- `Review Standard`: establish the two-second test as a lab review gate

## Integration Points

- Add the page to the `Lab Resources` toctree and overview list.
- Cross-link it from `data-management` because that page already discusses figure presentation and image handling.
- Cross-link it from `meetings` because one-on-one preparation is one of the immediate motivations for adding this policy.
